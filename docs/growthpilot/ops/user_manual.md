# 42 用户操作手册（简版）

> 覆盖范围：`QA-35`
>
> 面向对象：super_admin / principal / teacher / finance
>
> 状态声明：本文先交付文字版操作手册、截图清单与常见问题。真实环境截图需在 UAT 或正式环境补拍后再固化。

## 1. 先看这个

系统围绕 4 条高频主流程展开：
- super_admin：管账号、角色、基础配置
- principal：看经营与学生成长总览
- teacher：做作业复核、习惯观察、成长目标跟进
- finance：看合同、账单、收款、退款

首次使用建议顺序：
1. 登录并确认当前角色与校区
2. 先跑一条自己最常用的主流程
3. 再看异常提示和筛选是否符合预期

## 2. 登录与通用导航

### 2.1 登录

1. 打开系统登录页。
2. 输入账号和密码。
3. 登录成功后进入 Dashboard。
4. 先确认右上角显示的当前账号、角色、校区是否正确。

如果登录失败，优先检查：
- 账号或密码是否错误
- 当前账号是否已分配角色
- 当前账号是否已绑定正确校区

### 2.2 通用导航

左侧导航按模块分组：
- 仪表盘
- 学生中心
- 家庭中心
- 教师中心
- 作业中心
- 成长中心
- 收费中心
- 设置中心
- 数据分析

通用操作规则：
- 列表页先用筛选，再打开详情
- 详情页优先查看顶部摘要，再看 tab
- 保存后必须刷新一次确认结果已落库

## 3. 按角色快速上手

### 3.1 super_admin

适合处理：
- 创建账号
- 分配角色和校区
- 维护基础字典
- 维护评分规则

首次登录后建议依次检查：
1. Dashboard 是否可打开
2. 用户管理页是否可访问
3. 基础字典是否可查询
4. 评分规则是否可查看和保存

常用入口：
- 用户与角色：`设置中心 -> 用户管理`
- 基础字典：`设置中心 -> 基础字典`
- 评分规则：`设置中心 -> 评分规则`

### 3.2 principal

适合处理：
- 查看经营和学生成长总览
- 抽查学生 360
- 查看教师分析、学生分析、收费分析

首次登录后建议依次检查：
1. Dashboard KPI 和趋势图
2. 学生列表筛选
3. 学生 360 各个 tab
4. 分析页切换学期后的变化

常用入口：
- Dashboard：`仪表盘`
- 学生 360：`学生中心 -> 学生列表 -> 选择学生`
- 分析：`数据分析`

### 3.3 teacher

适合处理：
- 查看待复核作业
- 保存教师复核结果
- 记录习惯观察
- 创建成长目标和跟进

首次登录后建议依次检查：
1. 作业复核队列是否有待处理数据
2. 打开一条作业详情并保存复核
3. 创建一条习惯观察
4. 创建一个成长目标并追加跟进
5. 到学生 360 复查数据是否串联成功

常用入口：
- 作业复核：`作业中心 -> 作业复核队列`
- 习惯观察：`成长中心 -> 习惯观察`
- 成长目标：`成长中心 -> 成长目标`
- 学生 360：`学生中心 -> 学生列表`

### 3.4 finance

适合处理：
- 查看合同和账单
- 核对收款记录
- 处理退款
- 跟进续费和欠费

首次登录后建议依次检查：
1. 合同列表是否可查询
2. 账单列表筛选是否准确
3. 打开账单详情查看应收、已收、未收
4. 抽查退款和续费字段

常用入口：
- 合同：`收费中心 -> 合同列表`
- 账单：`收费中心 -> 账单列表`
- 收款记录：`收费中心 -> 收款记录`

## 4. 核心操作流程

### 4.1 查看学生列表并进入学生 360

1. 打开 `学生中心 -> 学生列表`
2. 输入姓名、学生编号或筛选学期/教师
3. 点击学生姓名
4. 在学生 360 中查看概览、作业、成长、家庭、收费

检查要点：
- 是否打开了正确学生
- 作业、成长、收费信息是否属于同一学生
- 是否存在空白 tab 或明显异常数据

### 4.2 创建账号并分配角色

1. 打开 `设置中心 -> 用户管理`
2. 点击“新建用户”
3. 填写基础信息
4. 选择角色和校区
5. 保存后用新账号重新登录验证

检查要点：
- 登录后菜单是否与角色一致
- 是否能看到该校区数据
- 是否误看到了不属于本角色的页面

### 4.3 教师复核作业

1. 打开 `作业中心 -> 作业复核队列`
2. 按日期、学生或状态筛选
3. 进入作业详情
4. 查看 AI 结果
5. 修改正确率、错因、风险等级、教师建议
6. 保存
7. 刷新页面确认结果仍在

检查要点：
- 保存后不丢数据
- 状态正确变化
- 同一条作业不会生成重复复核

### 4.4 记录习惯观察

1. 打开 `成长中心 -> 习惯观察`
2. 选择学生
3. 录入习惯维度分数和评语
4. 保存

检查要点：
- 分数范围正确
- 保存后能在列表或学生 360 中看到记录

### 4.5 创建成长目标并添加跟进

1. 打开 `成长中心 -> 成长目标`
2. 选择学生并创建目标
3. 设置目标内容、阶段、负责人
4. 保存后追加跟进记录

检查要点：
- 目标状态是否合理
- 跟进记录是否保留时间和内容

### 4.6 查看账单、收款和退款

1. 打开 `收费中心 -> 账单列表`
2. 按学生、合同号或状态筛选
3. 打开一条账单
4. 查看应收、已收、未收
5. 查看收款记录
6. 如有退款，检查退款记录和账单状态

检查要点：
- 金额是否一致
- 账单状态是否自动更新
- 是否存在重复收款或异常负数

## 5. 出错时先怎么判断

### 5.1 登录后看不到菜单

可能原因：
- 当前账号没有对应角色
- 当前账号未绑定校区
- 当前环境加载的是错误数据或旧缓存

建议动作：
1. 退出重新登录
2. 让 super_admin 检查角色和校区绑定
3. 记录账号、时间、截图，交给 QA

### 5.2 学生数据为空或不全

可能原因：
- 筛选条件过严
- 当前角色没有该校区权限
- UAT 数据尚未导入或导入不完整

建议动作：
1. 先清空筛选条件
2. 核对当前校区和学期
3. 对照样本学生编号复查

### 5.3 保存后数据消失

可能原因：
- 页面未真正保存成功
- 保存后状态未回写
- 有并发覆盖或刷新加载旧数据

建议动作：
1. 记录操作步骤
2. 截图保存前和刷新后的差异
3. 把时间、角色、页面地址交给 QA 建缺陷

### 5.4 上传或下载失败

可能原因：
- 文件大小超过限制
- 网络或对象存储异常
- 当前环境配置未完成

建议动作：
1. 先换一个小文件重试
2. 记录失败提示与时间
3. 交给 QA 和技术支持排查

## 6. FAQ

### 哪些角色能看学生 360？

通常是 `super_admin`、`principal`、`teacher`。如果看不到，先检查角色和校区权限。

### 为什么同一学生在不同页面看到的数据不一致？

优先排查：
- 当前学期是否一致
- 当前校区是否一致
- 是否打开了旧标签页
- 是否是 UAT 迁移数据未同步完成

### 退款后为什么账单状态变了？

账单状态会根据应收、已收、退款结果自动变化。若金额与状态不一致，应立即登记缺陷。

### 我只想看自己负责的学生，怎么确认范围对不对？

先看列表筛选，再抽一名自己负责学生和一名非负责学生核对访问权限。如果出现串数或越权，立即反馈 QA。
