# 13 历史表迁移映射

## 1. 源表概况

| 来源表 | 主要内容 | 处理策略 |
|---|---|---|
| 学生档案表 | 学生名、年级、负责老师、历史作业日期串、习惯评分日期串、学生编号 | 仅作为 student 主档补充与历史汇总参考 |
| 2025下半学年学生信息表 | 学生基础、家长联系方式、入学离校、是否单亲、外补习情况 | 迁入 students / families / enrollments / external_courses |
| 2026上半学年学生信息表 | 同上 | 同上 |
| 2025下半学年每日作业完成质量表 | 作业图片、AI Markdown、正确率、错因 | 迁入 homework_* |
| 2026上半学年每日作业完成质量表 | 同上 | 同上 |
| 2026上半学年学习习惯评分表 | 单次习惯评分记录 | 迁入 growth_observations + scores |
| 2026每日作业时间统计表 | 基本为空 | 忽略或作为模板表 |
| 作业时间统计表 | 目前几乎无数据 | 等待后续设备/手工采集后启用 |
| 设备签到记录表 | 目前几乎无数据 | 作为 attendance_events 种子 |
| 作业时间记录设备绑定表 | 学生编号/学生名/设备SN | 迁入 student_device_bindings |

## 2. 已观察到的历史数据问题

1. 学生表按学期拆分，无法唯一标识学生生命周期
2. `学生档案表` 中 D/E/F/H 列是**逗号拼接日期串**，不是事务明细
3. 作业表中 E/F 列存在重复 AI 输出
4. 学生信息表日期是 Excel serial，需要转成 ISO 日期
5. 多个字段为空：
   - 家长联系方式
   - 照片
   - 设备 SN
6. 作业时间、签到、习惯评分数据量极少，不能直接支撑统计口径
7. 源 Excel 含无效数据验证范围，建议先导出 CSV 或修复后再导入

## 4. 字段清洗规则

### 4.1 学生去重
优先级：
1. 学生编号完全一致
2. 姓名 + 年级一致
3. 姓名一致 + 负责老师一致 + 学期连续

### 4.2 老师去重
以姓名为主键候选，先生成 teacher 种子表：
- 胡忠芸
- 肖顺英
- 田仙雨

### 4.3 学科标准化
- 数学 -> `math`
- 语文 -> `chinese`
- 英语 -> `english`

### 4.4 错因标准化
建议映射到以下 code：
- 概念混淆 -> `CONCEPT_CONFUSION`
- 方法未掌握 -> `METHOD_NOT_MASTERED`
- 计算失误 -> `CALCULATION_ERROR`
- 审题偏差 -> `MISREAD_QUESTION`
- 知识混淆 -> `KNOWLEDGE_CONFUSION`
- 遗漏作答 -> `MISSING_ANSWER`
- 表述不清 -> `UNCLEAR_EXPRESSION`
- 步骤缺失 -> `MISSING_STEPS`
- 非知识性错误 -> `NON_KNOWLEDGE_ERROR`
- 无/无知识性错误 -> `NO_ERROR`

### 4.5 百分比转换
`"85%" -> 85.00`

### 4.6 日期转换
Excel serial：
- 45901 -> 2025-09-01
- 46083 -> 2026-03-02
- 46104 -> 2026-03-23

## 6. 推荐中间层 staging 表

```text
staging_students
staging_enrollments
staging_homework
staging_growth_scores
staging_devices
```

staging 表要求：
- 保留 `source_sheet`
- 保留 `source_row_no`
- 保留 `raw_payload`
- 保留 `import_batch_id`
- 不做业务外键

## 7. 导入后校验

### 7.1 数据量校验
- students 数量 >= 学期表去重后学生数
- homework_submissions 数量 = 两张作业表总行数
- homework_ai_analyses 数量 = 作业提交数
- growth_observations 数量 = 习惯评分表数据行数
- devices / bindings 数量 >= 设备绑定表非空 SN 数量

### 7.2 质量校验
- 不存在孤儿 submission.student_id
- 不存在孤儿 enrollment.student_id
- 不存在 invoice 无 family_id / student_id
- 百分比字段全部为 numeric
- 日期字段全部为 ISO date

## 8. 不建议导入的字段

- 学生档案表内的“历史日期串汇总列”作为独立事实表
- 重复 AI 原文列的第二份副本
- 空白照片链接占位值
- 无实际设备号的绑定记录
