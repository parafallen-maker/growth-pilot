## 1. 首次登录

### super_admin

1. 打开系统首页
2. 输入账号密码登录
3. 首次登录后进入 Dashboard
4. 先检查当前校区、角色、菜单权限是否正确

截图位：
- 登录页
- Dashboard 首页
- 系统设置页

### principal

1. 登录后查看 Dashboard 总览
2. 打开学生 360
3. 查看教师排班与分析报表

截图位：
- Dashboard
- 学生 360
- 分析报表

### teacher

1. 登录后进入作业列表
2. 打开一条提交记录
3. 完成教师复核
4. 录入习惯观察或成长目标

截图位：
- 作业列表
- 复核工作台
- 成长记录页

### finance

1. 登录后进入合同或账单列表
2. 查看收款记录
3. 处理退款或续费跟进

截图位：
- 合同列表
- 账单详情
- 收款或退款页

## 2. 常用操作

### 2.1 查看学生列表

1. 打开“学生管理”
2. 使用姓名、学期、老师筛选
3. 点击学生姓名查看详情

### 2.2 教师复核作业

1. 打开“作业管理”
2. 按班级或日期筛选
3. 进入详情页查看 AI 结果
4. 修改后提交复核

### 2.3 财务查看账单

1. 打开“收费管理”
2. 进入“账单列表”
3. 按合同号或学生筛选
4. 查看账单状态与收款记录

## 3. FAQ

### 登录后看不到功能菜单

原因：
- 当前角色没有对应权限
- 当前账号未绑定校区

### 学生数据为空

原因：
- 当前筛选条件过严
- 迁移数据还未导入当前环境
- 当前角色没有该校区数据权限

### 上传文件失败

原因：
- 文件超过大小限制
- 网络或对象存储异常
