## 7. 回滚步骤模板

### 7.1 应用回滚
1. [ ] 停止新版本 Web / API 流量进入
2. [ ] 切回上一稳定版本镜像 / commit
3. [ ] 清理新版本临时任务与缓存（如有）
4. [ ] 校验健康检查恢复

### 7.2 数据回滚
> 原则：先止血，后修数。不要边冒烟边找灭火器。

1. [ ] 判断是否涉及结构变更
2. [ ] 判断是否需要数据库 point-in-time restore / 手动修复脚本
3. [ ] 按备份记录恢复数据库
4. [ ] 恢复对象存储快照（如附件/导入受影响）
5. [ ] 回放必须保留的业务增量（若有明确方案）

### 7.3 回滚后验证
- [ ] 管理员登录成功
- [ ] 学生列表 / student360 正常
- [ ] homework 详情与 review 状态可读
- [ ] growth 报告草稿可读
- [ ] invoice / payment / refund 状态一致
- [ ] 日志恢复正常、无持续告警
