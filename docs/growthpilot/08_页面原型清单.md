# 08 页面原型清单

> 说明：这里是**低保真结构原型**，目的是让前端工程和大模型直接按“页面区块 + 数据依赖 + 交互动作 + 状态处理”实现。不是视觉稿。

## 页面模板说明

每个页面按以下格式描述：
- 路由
- 页面目标
- 角色
- 顶部操作
- 数据区块
- 行为/弹窗
- API 依赖
- 异常状态

## P01 登录页 `/login`

- 目标：账号密码登录，刷新 token，进入首页
- 角色：全部后台用户
- 区块：
  1. Logo/标题
  2. 用户名
  3. 密码
  4. 登录按钮
- 行为：
  - 登录成功跳转 `/dashboard`
  - 登录失败展示错误提示
- API：
  - `POST /auth/login`
- 状态：
  - loading
  - error

## P02 首页总览 `/dashboard`

- 目标：负责人快速看到运营全局
- 角色：super_admin, campus_admin
- 顶部筛选：校区、学期、日期范围
- 区块：
  1. KPI 卡片：在读学生数 / 待复核作业 / 本周未发周报 / 本月应收 / 本日签到异常
  2. 作业待复核看板
  3. 成长执行看板
  4. 收费提醒
  5. 快捷入口
- API：
  - `GET /analytics/overview`
- 跳转：
  - KPI 卡片点击进入对应列表页

## P04 学生 360 `/students/:studentId`

- 角色：campus_admin, growth_advisor, subject_teacher, service_staff

  - 快捷动作：编辑 / 新建观察 / 上传作业 / 新建合同 / 新建家庭任务

  1. 概览：关键指标卡、最近动态、老师摘要
  2. 基础信息：主档字段、在读档、标签
  3. 家庭：家庭、监护人、接送联系人

  8. 沟通：沟通记录、会谈、外发消息
- API：
  - `GET /students/{studentId}`
  - `GET /students/{studentId}/360`

## 页面级统一状态约定

每个页面都要实现：

- `loading`：Skeleton，不要只放 spinner
- `empty`：有明确空状态文案和引导动作
- `error`：展示错误详情和重试按钮
- `permissionDenied`：403 页面或局部禁用
- `offline`：可选，针对上传和发送任务做弱提示

## 页面级统一组件约定

- 统计卡：`MetricCard`
- 筛选栏：`FilterBar`
- 列表表格：`DataTable`
- 详情抽屉：`DetailDrawer`
- 编辑弹窗：`FormDialog`
- 时间线：`TimelinePanel`
- 趋势图：`TrendChart`
- 上传器：`FileUploader`
- AI 结果卡：`AiResultCard`
