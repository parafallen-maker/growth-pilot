# 41 运维手册

> 覆盖范围：`QA-34`
>
> 状态声明：本手册交付运维流程、常见排障、备份恢复与联系人模板；真实环境命令以正式部署资产为准。

---

## 1. 服务架构

```text
Internet
  -> DNS
  -> Nginx / TLS
     -> Web (Next.js)
     -> API (NestJS)
        -> PostgreSQL
        -> Redis
        -> S3-compatible storage
```

关键说明：
- Web 与 API 可以分容器或分主机，但入口必须固定
- 健康检查统一看 `/health` 与 `/health/ready`
- 迁移、部署、备份都必须写操作日志

---

## 2. 服务启停命令

### 2.1 Docker Compose 方式

```bash
docker compose -f docker-compose.prod.yml ps
docker compose -f docker-compose.prod.yml up -d
docker compose -f docker-compose.prod.yml restart api
docker compose -f docker-compose.prod.yml restart web
docker compose -f docker-compose.prod.yml down
```

### 2.2 单服务查看

```bash
docker compose -f docker-compose.prod.yml logs api --tail 200
docker compose -f docker-compose.prod.yml logs web --tail 200
docker compose -f docker-compose.prod.yml logs db --tail 200
```

---

## 3. 日志查看

优先顺序：
1. Docker logs
2. `/var/log/growthpilot/*.log`
3. 外部日志系统（如有）

排查时至少抓取：
- 报错时间窗口前后 10 分钟
- 对应 traceId / requestId
- 相关用户、批次、文件名

---

## 4. 常见问题排查

### 4.1 首页无法打开

检查：
- Nginx 是否存活
- Web 容器是否 healthy
- DNS 是否已正确指向

### 4.2 登录失败

检查：
- `JWT_SECRET` 与 API 实例是否一致
- `/auth/login` 是否返回 200/401
- 浏览器 cookie / token 是否正确写入

### 4.3 学生列表为空

检查：
- 迁移批次是否执行成功
- 数据库连接是否正常
- 当前账号是否有校区数据权限

### 4.4 文件上传失败

检查：
- `S3_*` 环境变量
- 存储桶权限
- 反向代理 `client_max_body_size`

### 4.5 数据库连接异常

检查：
- `DATABASE_URL`
- DB 连接池占用
- 最近是否刚执行 migration 或大批量导入

---

## 5. 备份与恢复

### 5.1 备份最低要求

- 数据库全量备份：每天至少一次
- 对象存储关键前缀快照：每天至少一次
- `.env.prod` 与反向代理配置变更前必须备份

### 5.2 恢复流程

1. 确认恢复范围：应用、数据库、对象存储、配置
2. 停止写流量
3. 恢复数据库
4. 恢复对象存储
5. 回滚应用
6. 执行冒烟验证
