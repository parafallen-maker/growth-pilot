# 04 数据库字典

> 本文档用于帮助大模型快速理解表的职责；字段细节以 `05_数据库DDL.sql` 为准。

## 1. 平台基础

| 表名 | 用途 | 关键字段 |
|---|---|---|
| `campuses` | 校区主表 | `code,name,status` |
| `school_terms` | 学期主表 | `campus_id,code,name,start_date,end_date,status` |
| `roles` | 角色主表 | `code,name,scope_level,status` |
| `permissions` | 权限点主表 | `code,name,module,action` |
| `role_permissions` | 角色权限关联 | `role_id,permission_id` |
| `users` | 后台用户 | `username,password_hash,display_name,status` |
| `user_roles` | 用户角色关联 | `user_id,role_id,campus_id` |
| `file_assets` | 文件资源 | `bucket_name,object_key,file_name,mime_type` |
| `system_dictionaries` | 系统字典 | `dict_type,code,label,sort_order` |
| `ai_jobs` | 异步任务 | `job_type,biz_type,biz_id,status,payload` |
| `operation_logs` | 操作日志 | `user_id,module,action,biz_type,biz_id` |
| `kpi_daily_snapshots` | 指标快照 | `campus_id,stat_date,metric_code,metric_value` |

## 9. 高优先级主表

- `students`：学生唯一主档
- `student_enrollments`：学期在读档，挂老师、校区、班组
- `families` / `guardians`：家庭结构与联系人
- `homework_submissions`：作业事件主表
- `homework_reviews`：教师正式结论
- `growth_observations` / `growth_goals` / `growth_reports`：成长主链路
- `contracts` / `invoices` / `payments`：收费主链路

## 10. 推荐索引重点

- 学生高频查询：`students(student_no)`, `students(name)`, `student_enrollments(student_id, term_id)`
- 作业高频查询：`homework_submissions(student_id, homework_date)`, `homework_submissions(ai_status, review_status)`
- 成长高频查询：`growth_observations(student_id, observation_date)`, `growth_goals(student_id, status)`
- 收费高频查询：`invoices(family_id, status, due_date)`, `payments(invoice_id, payment_time)`
- 出勤高频查询：`attendance_events(student_id, event_time)`, `homework_time_daily_stats(student_id, stat_date)`
